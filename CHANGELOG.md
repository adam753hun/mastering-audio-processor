# Changelog

## 0.2.0 — 2026-11-01 · Build 20261101.02

- Hungarian/English UI selector in Settings → Interface; applies on Save without restart.
- Persisted language preference, independent of audio presets.
- Translated dialogs, help, status messages, validation labels and log descriptions.
- International audio terms retained in Hungarian labels.
- Translation completeness, Save/Cancel, startup migration and sample-identity checks.

- Magyar/angol nyelvválasztó a Beállítások → Felület fülön, azonnali váltással Mentés után.
- Külön mentett felületi nyelv; a preset és a DSP változatlan marad.
- Fordított üzenetek és súgók; angol szakkifejezések a magyar felületen is.

## 0.1.0 — 2026-11-01

- First standalone public C#/.NET 8 Windows Forms edition.
- Initial-noise stationary denoising based on noisereduce, with optional bypass.
- Optional speech compression and expander/gate.
- Loudness matching, oversampled peak protection and PCM export checks.
- Whole-profile presets, safe output folders and duplicate protection.
- Background batch processing with file-boundary pause/resume/stop.
- English/Hungarian documentation and comments, synthetic integration checks.
- GPL-3.0-only project licence; retained MIT notice for noisereduce.

## 0.1.0 — Magyar

- Első önálló publikus C#/.NET 8 Windows Forms kiadás.
- Kezdő zajmintás stationary zajszűrés, bypass lehetőséggel.
- Opcionális kompresszor, expander/gate, LUFS és csúcsvédelem.
- Presetek, biztonságos kimeneti mappák, fájlnévütközés-védelem.
- Háttérfeldolgozás, fájlhatáron szünet/folytatás/megállítás.
- Magyar/angol dokumentáció, kommentek és generált hangos tesztek.
